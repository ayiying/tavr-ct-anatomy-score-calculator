# TAVR CT Anatomy Score Calculator

This research-use static web calculator estimates the 30-day probability of VARC-3 Device Success after self-expanding TAVR in patients with pure aortic regurgitation.

It does not estimate individualized MACE risk and is not intended for clinical decision-making. All calculations are performed locally in the browser; no user-entered data are uploaded or stored.
